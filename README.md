# Ryan Allen: ePortfolio

Source of https://ryanallen2004.github.io, my industrial engineering portfolio. It's plain static HTML, CSS and JavaScript served by GitHub Pages, with no build step and nothing to run.

- `index.html`: home page (projects, Germany 2027–28, experience, skills, contact)
- `hillpark/`, `parking-model/`, `race-car/`, `transportation/`: one page per project
- `assets/`: stylesheet, script, map data, images and my résumé

The pages are generated by a small Python script I keep outside this repository, so edit that rather than these files when possible.

Map data: University of Arkansas campus map and © OpenStreetMap contributors (ODbL). Built with help from Claude (Anthropic).
